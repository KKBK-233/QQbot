# 仓库精简与目录整理

日期：2026-10-19。本轮针对维护量精简源码，不改变其他功能开关，不部署新工作流，不改记忆模块或用户未提交工作。

## 删除

- 旧 Python 沙箱删除 16 个文件：工具、预算、运行器、隔离 worker、启动/终止入口、安装/部署/退役脚本和专用测试。下架检查移到 checks，历史源码通过 Git 恢复。
- 删除 5 个独立的一次性旧补丁：历史图片读取、图片任务路由、点名优先、回复超限和视觉路由。没有在当前受控部署脚本中发现调用方。
- 删除 5 个个案探针：固定历史图片请求、规划与回复快照、回复超限回放及下载研究快照核验。它们依赖特定旧数据或研究目录，不作为持续验收入口。

共删除 26 个文件。生产实例里已复制的历史维护脚本和退役备份未在本轮批量删除，运行数据与源码清理分别处理。

## 分类

- `scripts/deploy/`：3 个部署入口，以及仍被动态调用的 3 个辅助模块。
- `scripts/checks/`：管理、沙箱下架、引擎、插件、网络和旧调度器检查。
- `tests/`：根项目 4 个离线测试模块，修正移动后的导入路径。
- `docs/history/`：本地旧首页的部署与诊断历史；现首页只描述当前状态与入口。公开快照不包含这份含本地个案的历史记录。

共移动 20 个文件。根目录被 Supervisor、启动脚本或当前模型接入引用的桥接文件固定路径保留。

任务插件部署会动态加载 `repair-visual-target.py`、`remove-tone-filter.py` 和 `enable-planner-thinking.py`，它们不是可直接删除的闲置源码，现与部署入口位于同一目录。图片辅助模块的相对路径已改为项目根路径。

Maisaka 仍承接其他会话，并向新引擎提供记忆工具和清理上下文的共用代码，本轮未整目录删除。`memory-fix`、`gif-fix` 和 `context-cache` 的可复现维护代码也保留。
