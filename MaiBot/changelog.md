# 变更记录

## 1.7.9 · 2026-10-22

- 模型适配：官方 DeepSeek 思考工具链完整回传原生 `reasoning_content`；普通调用及其他提供方保持原协议，思考摘要不会冒充原生内容。
- 对话引擎：遇到空正文时，已有的一次补试关闭接口强制 JSON 模式；提示词中的 JSON 动作协议及本地校验保持启用，不增加模型尝试次数，不重跑已执行的工具。明确拒绝不补试。
- 搜索交付：模型失败或预算耗尽时，群内最多展示三条来源、每条六十字符摘录，资料部分上限六百字符；完整证据保留，错误仅展示首句原因。
- 诊断：记录原始响应字段的形态和长度，不记录原始思考或拒绝正文。

验证使用离线接口替身覆盖请求组装和工具续接，不代表已证实上游空输出发生率降低。线上部署和真实群聊效果需要分别验证。
