# Changelog

## [1.0.2] - 2026-10-21

- 修复当前消息和引用消息原图读取：SDK 已返回消息字典，插件不再重复解包为成功包装。
- 取图测试仅模拟 Host RPC，经过真实 SDK 能力代理与解包；覆盖当前图、引用图和缺图，避免模拟返回值与运行时不一致。
- 缺图时明确说明尚未请求反查引擎，不误报为搜索无结果或要求用户提供 Base64。

## [1.0.1] - 2026-10-21

### 主要功能

- 群内 `/搜图`、`/搜番` 通过 Command 落到同一搜索服务；支持当前消息原图与引用消息原图。
- `image_reverse_search` 工具接入 KKBK agent 工具白名单，自动读取宿主注入的当前/引用消息原图，无需用户提供 URL 或 Base64。
- ascii2d 同时覆盖色街模式与 bovw 特征模式，单模式失败不影响另一模式结果。

### 细节

- SauceNAO 等需要 key 的来源在缺 key 时返回结构化“跳过”，不抛异常、不中断链路。
- 报告按来源标注命中/低分/缺 key 跳过/超时/限流/无结果/失败。
- 新增引用消息图片定位所需的 `message.get_by_id` 能力和宿主消息 ID 注入。

## [1.0.0] - 2026-10-21

### 主要功能

- 新增群内图片反查：`/搜图` 按 SauceNAO → ascii2d → IQDB 顺序搜索，命中即停。
- 新增 `/搜番` 与 `/搜图 番剧`：番剧截图优先走 trace.moe，再回退二次元链路。
- 新增 `image_reverse_search` 工具，支持图片 URL / Base64 与插画/番剧模式。

### 细节

- 单引擎独立超时、限流与异常自动降级，全部尝试记录随结果返回。
- 全部不中时输出低分候选汇总；完全无结果时输出各引擎状态。
- SauceNAO / trace.moe key 支持配置与环境变量，日志和回复统一脱敏。
- 引擎顺序、阈值、超时和低分展示数量均可通过配置覆盖。
